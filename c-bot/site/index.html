Technical safeguards

The browser never owns the session token.

Authenticated requests include secure cookies automatically. The application does not put JWTs in local storage, URL fragments, or browser-readable JavaScript state.

  • Root-domain sessionSecure, HttpOnly, SameSite=Lax cookie scoped to .somasyncai.com.
  • Same-site calendar callsCredentialed HTTPS requests to the calendar subdomain use the same browser session.
  • Fail closedProduction configuration rejects insecure HTTP WebSocket or API endpoints.
